关于 FreshKeeper

FreshKeeper 是一款简单好用的食品与物品到期提醒工具，支持分区管理与搜索操作，离线可用，核心功能永久免费，无广告、不追踪。

快速开始

  1. 在首页点击“+”添加物品，填写名称与保质期。
  2. 选择分区（冷藏/冷冻/室温）或自定义分区。
  3. 在设置中调整提醒时间（到期前 N 天）。
  4. 备份：设置 > 备份与恢复 → 导出为 JSON；恢复选择导入 JSON。

常见问题（FAQ）

如何备份/恢复？

进入「设置」→「备份与恢复」。导出时使用系统分享面板选择 Save to Files；导入时从 Files 选择先前的 JSON 文件。

是否收集个人数据？

不收集。数据仅保存在你的设备本地；不集成广告或统计 SDK。

通知收不到怎么办？
  • 系统设置 → 通知 → 允许 FreshKeeper 通知。
  • 确认未开启专注/低电量模式限制通知。
  • 物品需填写到期日期且提醒时间早于到期日。
